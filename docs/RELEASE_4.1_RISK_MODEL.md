# 4.1-风险模型

日期：2026-10-16。版本分支：`4.1-风险模型`；源码包版本：`4.1.0`。

本版本保存当前网站及风险模型接入代码，基于原风险分析/报告界面扩展动态计算，不另起替代页面。本次提交、推送不是云端部署操作，也不修改原网站配置。

## 版本内容

1. 接入 NHANES v5 CPU XGBoost / CatBoost 模型组，支持单人当次指标估计和整份上传文件群体计算。每人请求 12 项结局，当前 basic 输入条件下 7 项有探索性数值，另 5 项因验证不足暂不出值。
2. 保留并动态计算指标分布、均值/中位数/四分位数、原生 SHAP、输入敏感性及联合响应等有对应计算依据的图；没有疾病概率或因果模型的原型图明确提示边界。
3. 群体原始基本资料置顶，包含总人数、模型输入覆盖、性别、年龄、婚姻与学历；模型结果单独展示，不把某个人当作整群代表。
4. 榜单与预警比例合并为整行卡片，内部虚线分隔。规范编号按原始行生成 `P-000001`，排序不改变编号，原始编号可追溯。
5. 综合分由共同有效结局的全群并列平均名次转为百分位后等权合成；默认阈值 80，可调整。达到阈值显示红色相对预警，数据充分且无人达到则显示绿色，数据不足独立显示，不补零、不强行输出结论。
6. 两个一键群体演示复用同一份 20 人公开数据与同一真实模型。普通演示预设 80，预警案例预设 75；当前实测分别为 0/20 与 1/20（5%）。这是显式界面演示阈值，不是两份不同患者数据，也不是临床高危界值。修改阈值不会重新训练或改变原预测。
7. 综合排序、所选结局排序、全群结果与报告导出使用一致的当前数据和阈值，保留所有对象、12 项结局及未出值原因。
8. 包含此前实现的数据清洗、格式恢复下载、单人动态特征图、公开描述性样本，以及 RAG 检索、引用、一般知识降级标注和模型服务适配代码。

## 新机器运行

前端需要兼容当前 Nuxt 依赖的 Node.js / pnpm；风险后端使用 Python 3.12+ 独立环境，不升级系统共享 Python。

从项目根目录运行（Windows PowerShell）：

```powershell
py -3.12 -m venv backend/.venv-prediction
backend/.venv-prediction/Scripts/python.exe -m pip install --only-binary=:all: -r backend/requirements-prediction.txt
cd my-nuxt-app
pnpm install --frozen-lockfile
cd ..
```

模型资产须由管理员从既有发布包另行准备。项目默认读取 `models/nhanes_v5`，也可以通过 `NHANES_MODEL_ROOT` 指向经过完整性核验的同版本资产。复制脚本支持显式来源，不包含模型训练流程：

```powershell
backend/.venv-prediction/Scripts/python.exe scripts/prepare-nhanes-local.py --source "E:/NHANES_XGBoost_Targeted_2009-2018_20261016_v5" --smoke
.\start-dev.bat
```

其中 E 盘路径是原开发机器的来源示例；其他机器需要替换为已取得的同版本发布包，不会由 GitHub 克隆自动生成。该脚本只复制经过核验的推理资产，不读取训练/测试 CSV，也不覆盖冲突资产。细节见 [模型运行说明](NHANES_LOCAL_MODEL.md)。

本地入口：`http://127.0.0.1:3000/risk?mode=batch`。API 状态：`/api/risk/status`。启动失败或缺模型必须按错误处理，不能用静态曲线或预存预测冒充成功。

## RAG 与部署边界

本地启动脚本可连接已安装的 Ollama，不自动下载模型；也支持通过私有环境变量配置兼容服务。完整语料、FAISS/MedCPT 索引和生成模型均不在 Git 中。只有实际资产和运行时就绪才可声称对应检索方式可用；MedCPT 不可用时的 BM25 降级须明确显示。

旧 `deploy/` 是此前 RAG 部署模板和历史记录，部分镜像使用 Python 3.11 且未安装预测依赖。不能直接据此宣称 4.1 风险模型已部署或新克隆即开箱可用。实际部署前应独立配置预测运行时、资产挂载、容量、应用凭证与 HTTPS，保留原站点回滚方案。

## 验证与安全范围

- 前端在当前代码上通过 `node --test tests/*.test.cjs`：124 项测试；`pnpm.cmd build` 成功。
- 浏览器实测普通/预警双入口、真实全群模型请求、75/80 阈值切换、综合榜单与比例、报告与 CSV 一致性。
- 后端及部署脚本测试从 `backend/` 目录执行 `.venv-prediction/Scripts/python.exe -m pytest tests ../tests -q`：525 项通过、5 项跳过。测试使用离线小样本、Mock 传输或已保存模型推理，不以工程测试通过宣称医学有效性。
- 这是 NHANES 美国一般人群横断面数据的当次生理/生化指标条件估计，不是未来发病概率、疾病诊断、职业人群外部验证或重金属因果效应。综合相对预警只用于本批次优先复核；绿色不是“健康或无风险”。

发布不包含：私有 `.env`、密钥、完整模型/检索资产、用户上传记录、虚拟环境、构建输出、操作备份，以及绑定个人 SSH 路径的历史运维脚本。公开 NHANES 演示文件及来源/完整性 manifest 保留在 `backend/app/data/`。

公开演示 CSV 有精确 SHA256 校验，`.gitattributes` 对这些资产禁用跨平台换行转换；克隆到 Windows/Linux 后均应保留原始字节，不应手动用编辑器另存换行。
