# 单人输入与参考值可视化契约

核验日期：2026-10-11。适用于单人数据接入页面，不改变群体导入、统计和图表流程。

## 真实输入，不构造人群统计

单人测量初始为空。每项测量独立选择样本、单位以及必要的检测/场景口径。缺失、非法数字、有效零值分别处理；不把输入过程中每次修改当作一次采样。

只有输入口径与来源条件匹配的指标才能计算 `测量值 / 参考值 × 100%` 及其相对偏移。不跨血液与尿液换算，不用未知肌酐值把尿浓度改成肌酐校正浓度。不将不同来源、不同性质的参考值合成为健康评分。

用户批准保留统一的卡片、配色、网格和交互风格，并允许把不适用的时间趋势图换成单次检测可比性矩阵。原先虚构的历史趋势、群体百分位、器官损伤归因、Z-score 和马氏距离不能由一次录入计算，必须更名为可计算的参考比较或数据完整性视图。

## 来源明确、适用条件明确的参考

| 指标与样本 | 来源数值 | 使用条件与性质 |
| --- | --- | --- |
| 全血铅 | 3.5 μg/dL = 35 μg/L | 成人明确全血；CSTE 暴露参考值，不是无害界限。达到参考值标记 `>=`。 |
| 全血镉 | 5 μg/L | 成人明确职业镉生物监测；美国 OSHA 行动参考。规则为超过 `>`，不是一般人群诊断值。 |
| 肌酐校正尿镉 | 3 μg/g Cr | 同上；明确肌酐校正尿样，不能套用于未校正尿浓度。规则 `>`。 |
| 全血汞 | <10 ng/mL = <10 μg/L | Mayo 的实验室参考区间上界；不能代表所有实验室或中国职业标准。达到上界标记 `>=`。 |
| 随机尿汞、肌酐校正 | 20 μmol/mol Cr | HSE 生物监测指导值；较稳定中长期职业汞接触、成人及随机尿。仅原单位比较，非疾病诊断。 |
| 随机尿毒性砷 | <35 μg/L | Mayo：无机砷与甲基化砷之和；明确砷分型结果，不能套用于总砷或 μg/g Cr。 |
| 住宅室内氡 | 100 Bq/m³ | WHO 住宅年均参考；不能套用于工作场所或瞬时读数。 |

来源：

- [CDC/NIOSH 血铅参考说明](https://www.cdc.gov/niosh/lead/bll-reference/index.html)：不同参考与监管规则并列，页面明确血铅存在即说明接触，参考以下不等于没有健康风险。
- [OSHA 1910.1027 镉](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.1027)：(l)(3) 规定职业监测条件及严格超过的边界；[采样协议](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.1027AppF) 区分全血和肌酐校正尿。
- [Mayo 全血汞 HG](https://pediatric.testcatalog.org/show/HG)：样本为全血，参考适用所有年龄，但这里不是检测方法等效性或临床判断的替代。
- [HSE 尿汞](https://books.hse.gov.uk/product/9780717667895)：随机尿肌酐校正指导值，适用相对稳定中长期职业接触。
- [Mayo 尿砷分型 SPAS](https://mml.testcatalog.org/show/SPAS)：毒性砷与总砷不同，尿样与浓度单位必须匹配。
- [WHO 氡](https://www.who.int/news-room/fact-sheets/detail/radon-and-health)：年均住宅参考，不是通用个人生物测量阈值。

这些数值分别属于暴露参考、职业监测行动参考、实验室参考上界和环境参考，不统一称为“安全限值”。本版未找到与当前输入充分匹配的 Th、Li、Cr、Ni、Co 参考，保留原测量与“无适用参考”状态，不使用原页面未经核实的数字，不把治疗性锂浓度当作健康人职业暴露阈值。

## 图表口径与实现边界

- 主柱图和雷达图：仅匹配指标的参考占比；100% 是对应参考位置，不是统一风险等级。雷达尺度统一且覆盖最大有效值。
- 可比性矩阵：实际录入、样本、单位、参考条件匹配状态；未录入不计为测量零。
- 排序水平图、偏移图：同一人的参考占比/相对偏移，不称群体百分位或 Z-score。
- 环图与仪表：指标录入状态/参考比较覆盖率，分母明确，不称器官损伤概率或健康综合评分。

输入修改后实时刷新，非法输入不继续沿用旧图数值。缺少条件时说明原因；有值但无参考的指标仍可查看原始值及单位。本版是客户端可视化计算，不等于单人数据库持久化、真实风险模型或临床验证完成。
