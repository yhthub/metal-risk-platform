# 面向职业金属复合暴露的智能干预推荐与决策支持系统

## 项目概述

本系统面向职业卫生与流行病学研究场景，融合环境监测、流行病学调查及多组学数据，构建基于因果推理的重金属健康风险评估与干预推荐模型。系统覆盖"暴露数据接入 → 多维可视化分析 → 风险量化预警 → 因果知识推理 → 智能干预策略生成 → 知识库问答"全链路决策支持。

## 技术栈

## 功能模块

### 1. 系统首页 (`/`)

项目门户页面，展示系统核心能力与学术定位。

- 顶部固定导航栏（评估模型 / 数据视图 / 因果图谱 / 系统文档）
- 全屏 Hero 区域：项目标题、副标题、核心使命标识
- 重金属元素浮动粒子背景动画（Pb、Hg、Cr、Cd、As 等 10 种）
- 数据波形粒子 SVG 动画
- 三组核心能力展示卡片（含 CSS 3D 透视交互、SVG 动画、因果推断网络可视化）
- 系统闭环声明：风险识别 → 因果解析 → 干预推荐 → 效果反馈
- 页脚含四大链接分区

### 2. 数据接入与特征工程 (`/datainput`)

职业暴露数据的结构化录入、批量导入与多维度可视化分析。

- **管道步骤指示器**：数据接入配置 → 多维可视化分析 → 风险推理模型
- **单人录入模式**：
  - 基础个体档案（ID、性别、年龄、暴露工龄）
  - 8 种核心重金属暴露指标（Pb、Cd、Hg、Th、Li、Cr、Ni、Co）
  - 伴生非金属与标志物（As、Rn）+ LIS 体检报告上传
  - 临床监测基线参考面板（10 项安全阈值）
- **群体导入模式**：CSV/XLSX 拖拽上传，解析 1,245 条样本数据
- **个体可视化仪表盘**：
  - 主柱状图：多金属相对暴露指数（安全/预警/危险三档），含筛选图例与 hover 详情弹窗
  - 核心元素密度分布图、历史监测时序 SVG 趋势线
  - Pearson 特征相关性热力图
  - 综合风险贡献环形图
- **群体可视化仪表盘**（ECharts）：
  - KPI 概览卡片（总人数、性别占比、高危人数）
  - 群体暴露工龄序列特征散点图
  - 综合靶器官风险评级占比环形图
  - 年龄结构南丁格尔玫瑰图
  - 车间特征均值 vs 国家基线雷达图
  - 致病因子超标率排行横向柱状图

### 3. 风险量化与预警 (`/risk`)

基于多模型的风险评估与综合预警控制台。

- **管道步骤**：全流程打勾完成态
- **数据源挂载**：Profile.csv、Biomarkers.lst、Exposure.csv 标签展示
- **模型选择器**：XGBoost / DNN / LightGBM / Random Forest / Bayesian Net
- **深度推理过程可视化**：5 步专家推理链（特征提取 → Delphi 基线匹配 → AHP 权重 → SHAP 归因 → DAG 构建），可展开/折叠
- **综合预警定级**：三级危险标识横幅
- **ECharts 可视化矩阵（6 图表并排）**：
  - 风险总览仪表盘（Gauge）
  - 五大多发病概率预测（Progress Bar）
  - 多金属暴露雷达图
  - SHAP 特征归因贡献条形图
  - 历史风险演化趋势折线面积图（2021-2026）
  - 多靶器官毒性分布热力图（5 金属 × 3 系统）
  - 毒性传导桑基图
  - 靶向因果推断网络 SVG（DAG 路径动画）
- **模型字典页脚**：5 个预训练模型的详细介绍

### 4. 风险评估深度报告 (`/risk/report`)

面向打印输出的正式风险评估长卷报告。

- A4 纸样式布局 + 防伪水印背景
- **高危人员排查清单**：5 人花名册表格（工号、部门、工龄、风险因子、综合指数），按等级着色
- **首要高危人员综合靶器官预测**：仪表盘 + 4 项疾病概率条形
- **重金属暴露结构与 SHAP 归因**：雷达图 + 10 项因子贡献条形图（正负双向）
- **风险演化时序与靶器官毒性**：折线面积图 + 热力图
- **桑基图与靶向因果网络**：SVG DAG 路径动画 + 推理文字
- 系统算法签名行 + 打印/存档按钮
- `@media print` 样式优化

### 5. 因果知识推理 (`/causal`)

全景多模态复合暴露有向无环图（DAG）可视化与反事实推演。

- **全局控制栏**：暴露因子选择（10 种金属多选）、目标疾病靶点（5 种多选）、暴露年限滑块、人群分组单选
- **KPI 指标卡片**：综合因果风险评分（数字滚动动画）、主导致病因子、推断置信度、最优干预优先级
- **核心 DAG 视口**：
  - ECharts 渲染 40+ 节点（暴露层 → 分子机制层 → 组织损伤层 → 临床疾病层 → 干预层）
  - 30+ 因果连线（带强度/置信度 tooltip）
  - 粒子流动连线动画（effectScatter + lines）
  - 鼠标滚轮缩放 / 拖拽平移 / 缩放控件 / 浮动图例
  - 节点点击弹出详情抽屉（机制说明 + 上下游关系 + SHAP 贡献度 + 文献引用）
- **反事实因果推演沙盘**：
  - 10 种金属暴露降低滑块 + 抗氧化/螯合治疗开关
  - 实时计算：当前基线风险 → 干预期望风险 + 量化干预收益
- **筛选联动**：控制栏参数变化 → KPI 动态更新 → DAG 图谱节点/连线过滤

### 6. 智能干预策略推荐 (`/plan`)

基于因果推理结果的 12 套多维干预预案矩阵。

- **全链路状态核验**：3 个管道步骤完成标签 + 数据文件挂载 + 提交人/时间
- **一键推演**：5 步策略推理过程可视化
- **四维干预维度**（Tab 切换）：
  1. 职业环境与工程阻断（全隔离调岗 / P100 面罩 / 无人化改造）
  2. 临床医疗与药物干预（EDTA 驱铅 / GSH 抗氧化 / 血液透析）
  3. 营养与代谢拮抗支持（钙锌离子竞争 / 果胶吸附 / 维C 食疗）
  4. 动态监测与随访预案（双周复查 / 靶器官监测 / 神经行为随访）
- **每套方案卡片**：执行指令 + 干预机制 + 双 ECharts 迷你对比图（暴露衰减 + 疾病降幅）+ hover 深度解析弹窗（周期/成本）
- **靶向阻断验证网络**：SVG DAG 显示干预节点阻断致病路径
- 底部操作：导出 PDF / 推送 EHS / 下发 HIS

### 7. 方案深度解析报告 (`/plan/specplan`)

单套干预方案的详细报 PDF 长卷。

- 路由参数接收（id + title）
- 干预对象与场景评估（Descriptions 组件）
- 风险触发条件（Pb 超标 124%、As 超标 105%）
- 干预目标清单（3 项目标，绿色图标）
- 四维阻断策略卡片（环境/防护/健康/管理，彩色顶边）
- 标准化临床路径（Steps 组件 + 3 日详细流程）
- 预期效果评估（生化指标 + 功能指标）
- AI 推荐算法依据（Delphi + AHP + XGBoost）+ ECharts 雷达图
- 审核签名 + 打印/导出按钮

### 8. RAG 知识库问答助手 (`/agent`)

基于检索增强生成的智能知识问答与决策溯源助手。

- **模型切换**：Causal-RAG-72B / Tox-Agent-Pro / Med-Decision-Max / DeepSeek-R1-Distill
- **知识库挂载**：9 个毒理学数据库可选（IARC、IPCS、ToxNet、NHANES、CTD 等），含自定义上传
- **对话界面**：
  - 欢迎页：输入框 + 知识库选择 + 深度思考开关 + 联网检索
  - 3 个快捷提问入口
  - 消息列表：用户气泡（蓝色）+ AI 气泡（白色带知识引用）
  - 深度思考过程可展开/折叠（含加载动画）
  - 结构化知识卡片（暴露源、分子机制、生物标志物、靶器官、证据等级）
  - 智能干预建议生成
  - 消息操作栏（复制/重新生成/赞/踩）
- **模拟知识库**：内置 Pb、As、Cd、Hg 四种重金属的毒理数据
- Toast 通知系统

## 数据流

```
数据接入 (datainput)
  │  单人录入 / 群体 CSV 导入
  │  8 种重金属 + 2 种伴生标志物
  ▼
多维可视化分析 (datainput dashboard)
  │  暴露指数评估 / 密度分布 / 相关性 / 风险占比
  ▼
风险量化预警 (risk)
  │  模型选择 (XGBoost/DNN/LightGBM/RF/Bayesian)
  │  仪表盘 + 雷达 + SHAP + 热力图 + 桑基图 + DAG
  │  → 深度报告 (risk/report) 打印输出
  ▼
因果知识推理 (causal)
  │  10 种金属全景 DAG (暴露→分子→组织→疾病→干预)
  │  反事实推演沙盘 (滑块模拟干预效果)
  ▼
智能干预策略 (plan)
  │  12 套四维干预矩阵 (环境/医疗/营养/监测)
  │  → 方案详情 (plan/specplan) 打印输出
  ▼
知识库问答 (agent)
  RAG Agent + 9 大毒理数据库 + 深度推理
```

## 项目特性

- **Nuxt 4 目录规范**：`app/` 目录兼容、Composition API + `<script setup>`
- **Element Plus 自动导入**：无需手动注册组件
- **ECharts 6 深度集成**：每个分析页面均含多实例图表，支持响应式缩放
- **全局公共组件**：Sidebar 侧边导航复用，统一顶栏布局模式
- **管道步骤指示器**：跨页面进度可视化（datainput → risk → plan）
- **推理过程可视化**：大模型思考链可展开/折叠
- **打印友好**：报告页面均含 `@media print` 样式
- **CSS 3D 交互**：首页卡片鼠标跟踪透视效果
- **SVG 动画**：因果路径流动、数据波形粒子、脉冲辉光节点
